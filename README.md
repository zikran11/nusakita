# NUSAKITA

NUSAKITA is a modern interactive website that celebrates Indonesia's culinary heritage through food, stories, ingredients, and regional traditions.

## Features

- Interactive Indonesia map
- Culinary journey
- Signature Indonesian dishes
- Menu collection with category filters
- Testimonials
- Food gallery
- WhatsApp ordering
- Responsive design
- Scroll-based animations

## Technologies

- HTML5
- CSS3
- JavaScript
- GSAP
- Google Fonts

## How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Run the project using Live Server.
4. Open `index.html` in your browser.
